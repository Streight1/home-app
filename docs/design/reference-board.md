# Reference board

Reference jsou pouze zdrojem obecných patternů. Do repozitáře nejsou vložené
cizí screenshoty, loga, ilustrace, marketingové texty ani fonty bez oprávnění.

## Reflect na GetDesign

- Zdroj: [veřejná ukázka Reflect](https://getdesign.md/design-md/reflect?category=ai-ml).
- Role: pouze vizuální inspirace pro HomeApp Aurora.
- Převzít: obecný jazyk hlubokého tmavého plátna, fialových a modrých akcentů,
  čisté typografie, měkkého světla a moderního productivity produktu.
- Přeložit: marketingový směr do klidného aplikačního shellu pro domácí agendu.
- Nekopírovat: logo a název Reflect, texty, ilustrace, screenshoty, proprietární
  assety, přesné komponenty ani layout jejich landing page.

HomeApp Aurora je vlastní projektový design systém. Není produktem Reflect,
oficiálním design systémem Reflect ani tvrzením o příslušnosti k této značce.

## WAI-ARIA Authoring Practices Guide

- Zdroj: [WAI-ARIA APG](https://www.w3.org/WAI/ARIA/apg/).
- Převzít: očekávaný focus management, role a klávesové ovládání menu, radio
  group, tooltipu a dialogu.
- Nekopírovat: ukázkový vizuální styl bez přizpůsobení Aurora tokenům.

## WCAG 2.2

- Zdroj: [WCAG 2.2](https://www.w3.org/TR/WCAG22/).
- Převzít: ověřitelné AA požadavky na kontrast, focus, target size, reflow a
  reduced motion.
- Nekopírovat: nic vizuálního; jde o normativní kvalitativní hranici.

## Běžné productivity patterns

Sidebar, navigation rail a bottom navigation jsou obecné patterny. HomeApp má
vlastní breakpointy, rozměry, české názvy a responsivní kompozici. Neodvozuje
přesný layout, identitu ani marketing z jiné aplikace.
