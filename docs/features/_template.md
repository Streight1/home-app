# Název funkce

## Stav

Jedna z hodnot: `Implementováno`, `Částečně implementováno`, `Plánováno` nebo
`Pozastaveno`. Uveď ověřitelné hranice.

## Účel

Jaký skutečný problém funkce řeší a co vědomě neřeší.

## Uživatelské scénáře

Konkrétní scénáře bez smyšlených dat a bez tvrzení o neimplementovaném chování.

## Uživatelské rozhraní

Routy, stavy načítání, chyby, přístupnost a použité feature komponenty.

## API

Metody, cesty, access mode, CSRF, vstupy, výstupy a odkazy na katalog endpointů.

## Datový model

Dotčené entity, jejich vztahy, omezení a transakční hranice.

## Autentizace a oprávnění

Požadovaná session, household členství, role a pravidla proti enumeraci.

## Validace a chybové stavy

Validace vstupů, stabilní chybové kódy a bezpečné uživatelské zprávy.

## Testy

Automatizované scénáře a případné manuální kroky, které nelze automatizovat.

## Známá omezení

Skutečné mezery a provozní omezení současné implementace.

## Budoucí možnosti

Nezávazné směry bez termínů; nejsou součástí implementovaného rozsahu.
